# Soloblog

[Soloblog](https://github.com/soloblog/soloblog) is a free, open source blog
and website for one person, run on your own server or hosting account. Write
in a calm editor, pick from 35 colour palettes, and build pages from sections.
Your posts are plain text files you own.

After installing, open the app. First-time setup asks for a setup token:
open Apps, select Soloblog, and copy it from its logs under Workloads, on the
lines marked `[setup]`.
